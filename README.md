# Учебный проект "Курсовая работа 1"
## Контекст
Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.
## Установка
Клонируйте репозиторий
```
git clone git@github.com:fess88888/Coursework_1
```
# Модуль main
Функция main_report. Главная функция, принимающая строку с датой и временем и возвращающая JSON‑ответ.
## Использование разработанных функций
### Модуль services
1. Функция get_most_profitable_cashback, которая возвращает JSON-строку с суммой кэшбэка по категориям за указанный месяц и год.
Возвращает:
        JSON-строку вида {"Категория": сумма}, отсортированную по убыванию сумм.
2. Функция finds_transfers, возвращает JSON со всеми транзакциями, которые относятся к переводам физлицам
    за указанный месяц и год.
Возвращает:
        JSON-строку вида {"Описание" (имя и первая буква фамилии с точкой): сумма},
        отсортированную по убыванию сумм.
### Модуль reports
1. Функция spending_by_weekday рассчитывает средние траты в каждый из дней недели за последние три месяца.
2. Декоратор report_result записывает результат выполнения функции в файл.
### Модуль views
1. Функция filter_transactions_by_date фильтрует транзакции по диапазону дат.
2. Функция get_card_info получает информацию по картам из DataFrame с транзакциями и
    возвращает список словарей с информацией по каждой карте.
3. Функция get_top_5_transactions возвращает топ‑5 транзакций по сумме платежа за период.
## Тестирование
Проект использует библиотеку pytest и модуль unittest mock для тестирования. Все основные модули проекта покрыты тестами, что позволяет обеспечивать стабильность и надежность кода. Тесты находятся в папке tests, и их можно запустить командой:
```
pytest --cov=src --cov-report=html
```
### Покрытие тестами
 1. Покрытие тестами составляет 80% и более.
 2. Основные модули имеют высокий уровень покрытия, подтверждающий корректность их работы.
 3. Отчет о покрытии можно найти в папке htmlcov, открыв файл index.html в браузере.
### Подробности
 1. Тесты включают проверку всех критических функций.
 2. Используются параметризированные тесты и фикстуры для различных сценариев.
